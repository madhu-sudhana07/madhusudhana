# Data Science & Exploratory Data Analysis Projects

This repository contains data analysis, exploratory data analysis (EDA), and machine learning projects developed using Python and Google Colab.

---

## 📌 Projects Included

### 1. Netflix Content Strategy & Catalog Analysis
- **Description:** Exploratory data analysis on the global Netflix catalog to evaluate content composition, release timing, and runtime patterns.
- **Key Insights:** Identified optimal release periods (July and December), genre distributions, and duration thresholds for movies (160 mins) and TV series (1–3 seasons).
- **Tools Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Google Colab.

### 2. Retail & E-Commerce Operations Analysis
- **Description:** Business case study analyzing consumer purchasing trends, delivery logistics, and sales performance across 100,000+ orders.
- **Tools Used:** SQL, BigQuery, Pandas.
